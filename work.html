🔍 Vulnerability Discovery

IDOR found via param tampering /user/{id}, exploited to access other users data. Documented with PoC curl, CVSS 7.5 High.

🛡️ BOLA Remediation

Fixed in middleware/authorization.ts — enforce owner check: token.userId must equal requested resource. Added Jest tests.

🔐 JWT Hardening

Migrated to httpOnly, Secure, SameSite=Strict cookies in lib/jwt.ts. Removed localStorage token exposure.

🚀 Public API Shield

Added rate limiting, method whitelist, CORS hardening in next.config.js. Public routes protected from abuse.
